## 0. 第3章の芯（視点の三段変化の完成）

- 第1章＝**来訪者が変**（個人の綻び／プレイヤーは気づかない）。
- 第2章＝**世界が変**（客観の綻び／気づき始める、でも確信できない）。
- **第3章＝自分が加担していた**（当事者／「降ろす」という日常語が反転する）。
- 争点**「完成」の開示**：妖精の完成（=閉じること／破滅の達成）と、司書の完成（=未完のまま回り続けること）が真正面から衝突する。
- **全員再訪・新顔ゼロ。** 痩せていく世界に新しい人間は来ない。再訪の差分（**変化した者／忘れた者／変わらない者**）が、そのまま恐怖になる。

## 4. 争点「完成」の開示設計

- **妖精は嘘を一つもついていない**、を最後まで維持する。妖精が語ったのは「目録を完成させ、館を復興させる」——それは字義どおり真実で、その完成が破滅と同義であることだけを語らなかった（§12.1 反転）。
- **妖精の完成＝閉じること**（目録が埋まり、書架が閉じ、世界が消え終わる）。**司書の完成＝未完のまま回り続けること**（予約枠が永遠に1件残る＝原理的に完成しきれない構造＝生きた図書館）。
- **幕切れの台詞**：「**あなたは、良い司書でした**」。E1（達成＝最悪）でこの言葉が労いに聞こえ、TRUE ではこの言葉の意味がプレイヤーの中で裂ける。**同じ一文が結末で別の色に見える**設計。
- **サブ主題「呼吸」**：反論素材＝「**新しい本は、一度も来なかった**」。第3章が全員再訪・新顔ゼロであること自体が、この一文の伏線になっている（入ってくるものが無く、出ていく＝降ろす、だけの世界＝呼吸をやめた図書館）。

## 5. 目録の要求順設計（感情の重さで並べる）

- 目録（偽の大義）が要求する「降ろすべき本」は、**感情的に重い本ほど後に**要求する。プレイヤーが**自分の親切の記録を、自分の手で降ろす**構造を最大化する。
- 終盤に置く重い3冊（★割り当ては要確認）：
  - **`b02-dragon-smith`（竜と鍛冶屋）＝母子の一冊**
  - **`b06-lullabies`（忘れられた童謡集）＝二度手渡した歌集**（第2章で child に二度渡した符合を効かせる）
  - **`b04-harbor-chronicle`（港の年代記）＝郷土史家の資料**
- これは**機構の変更ではなく執筆・提示順の設計**（`computeCatalog` は erasedBooks 依存で順序非依存のまま）。要求順は ch3 来訪者の要望・整理圧の並べ方で表現する（付録A-2）。

## 6. 開閉管理

**開く（第3章で初めて説明せず提示する）：**
- searchBlock の機構発動（beat 13）
- 消失の自覚（当事者性・beat 14〜17）
- 地下書庫（beat 18）
- 争点「完成」（beat 18 対峙）
- 先代の真実＝手記（道半ばで手を止めた良心の跡）
- 妖精の名（**目録ではなく私信＝手記に残っていた**）

**最後まで説明しないもの（温存・非開示）：**
- **妖精の正体の全貌**（§12.2 の「破滅」動機は台詞で説明しない。ずれの提示までに留める）
- **「降ろす＝消える」の機序の理屈**（因果は最後まで言語化しない）
- searchBlock/目録/消失の**機構語彙**は player-facing に出さない（コメントのみ、の規律継続）

## 7. conscience（第3章での続き）

- **不可視・周回永続で加算**を継続。題材は当事者性に合わせる：
  - beat 13：searchBlock 不発の後「childの言い分を思い出す／気に留めず流す」
  - beat 17：金色の絵本の証言に「一緒に探そうとする／曖昧なままにする」
  - beat 18：整理を勧める妖精に対し「手を止める／続ける」——**これが truthReached 契機と同居**（§12.6：真相到達の行動は同時に conscience を上げる）。
- 規約不変：**正解を作らない・単発で効かせない・+1肢の位置分散を維持**（§12.5／第2章F是正の継続）。

## 8. 綻びの配置と強度

- **主綻び：** searchBlock（beat 13）＝第3章の開幕の一撃。断定はプレイヤーに委ねる（「探し方が悪かったのかも」の逃げ道は残すが、childとの符合で疑いは濃くなる）。
- **環境綻び：** townSimplify 深化（beat 14）。第2章より一段進んだ簡素化。
- **記憶綻び：** visitorAmnesia が**確信の供給源（郷土史家）**を食う（beat 15）＝第2章の「記録の穴」を、証人自身の欠落へ反転。
- **温存の解禁：** 地下書庫・消失そのもの・妖精の綻び（是正3）を beat 17〜18 で解禁。
- 強度指針：第1章「気づかない」→第2章「気づくが確信できない」→**第3章「認めざるを得ない、しかも自分の手で」**。

## 9. エンディング分岐の設計（beat 18）

実装は `determineEnding`（§12.6・3条件）に一致させる。優先：**TRUE → E3閉架 → E4継承 → E1良き司書 → E2空の書架**。

| エンド | 成立条件（既存判定） | 第3章での意味 |
|---|---|---|
| **TRUE** 救済 | `truthReached && アンカー保全 && conscience≥基準` | 妖精の名を呼び、金色の絵本を child に読み聞かせる。救済フォーム切替（一度きり） |
| **E3** 閉架 | `truthReached && chose-close` | 真相に至り、図書館を閉じる選択 |
| **E4** 継承 | `chose-bequeath` | 台帳を次の司書へ遺す（次周への導線） |
| **E1** 良き司書 | `ledger.length ≥ 目安` | 完成＝最も多く消した＝最悪の反転。「あなたは、良い司書でした」 |
| **E2** 空の書架 | 上記いずれも不成立 | ほとんど渡さなかった。誰も救えないが世界は残る |

- **TRUE 最終行動：** 金色の絵本を child に読み聞かせる＋妖精の名を呼ぶ＝救済（§12.6 救済＝対話イベント、システム通知にしない）。**このときのみ**妖精が救済時の姿へ変わる（§12.2 フォーム2状態）。
- ★分岐の選択肢文言・対峙の台詞は beat 18 執筆セッションで詰める。

各案の詳細（元の洗い出し）は以下。

### A-1. `truthReached` を立てる契機（未配線）

- 現状：`FLAG_TRUTH_REACHED='truth-reached'` は定義のみ。`determineEnding` は参照するが、立てる箇所が無い。
- **提案：** beat 18 の「妖精の勧める整理を拒む／地下で消えた本を確かめる」選択（§12.6 の契機）に、`Choice.flags=['truth-reached']` と `conscienceDelta:+1` を**同居**させる。真相到達の行動が同時に人柄も映す、という設計と一致。
- 代替：地下書庫画面への遷移そのもの（beat 17→18）で自動セットも可。ただし「プレイヤーの選択で立つ」方が当事者性が強い。★どちらか要判断。

### A-2. 目録の要求順（機構変更は不要）

- `computeCatalog` は `erasedBooks` 依存で順序非依存＝**変更不要**。
- 「重い本を後に要求」は**執筆レベル**で表現：ch3 来訪者の要望本・整理圧（clerk 的圧の再現）を、b02/b06/b04 が終盤に降ろされる並びに設計する。donationQueue／要望の割り当てで制御。

### A-3. 予約枠 `cat-final` の正体開示（UI・フラグ）

- 現状：`CatalogPage` は `bookId=null` を「──」で淡く表示、`remaining` に常に1残す。
- **裁定・実装済（Ch3-M）：** 開示フラグ `catalog-final-revealed` を新設。v17完了後に目録を開くと成立し、`cat-final` 行が表示題「**金色の絵本（題不詳）**」へ変わる（`remaining` 据え置き＝開示後も埋まらない＝完成不能を維持）。目録は絵本を記述できても名指せない（名は目録に載らない原則を目録自身に演じさせる）。
- 注意：これは「収蔵済」への変化**ではない**。「何が欠けていたか」が分かるだけで、欠落は戻らない（§12.4 の思想と一致）。★表示題・開示演出は要判断。

### A-4. エンド分岐フラグ `chose-close` / `chose-bequeath`（未配線）

- 現状：両フラグは定義のみ。`determineEnding` は参照するが立てる箇所が無い。
- **提案：** beat 18 対峙の選択肢に `Choice.flags` で付与（閉じる→`chose-close`／遺す→`chose-bequeath`）。TRUE は truthReached＋2ゲートで別途成立するため、選択肢は E3/E4 を主に制御。

### A-5. 終幕の画面遷移・救済フォーム（未実装）

- 現状の画面：`intro / interlude / reception / shelf / archive / ledger / closed`。来訪者のいない地下書庫（beat 18）に対応する画面が無い。

## 第3章のプレイ体験（3〜4文）

第2章を「やっぱりおかしい、でもまさか」で抜けたプレイヤーは、教師が探した一冊が検索に出てこない瞬間に、あの子の言い分を思い出す——**今度は自分が「見たのに無い」を体験する**。再訪する常連たちは、消失を進行させた者・忘れてしまった者・変わらず明るい者としてばらばらに欠けていき、記録の穴を数えた郷土史家までが自分の調べを忘れている。金色の絵本の話に押されて地下へ降りたプレイヤーは、先代の手記と妖精の名を見つけ、「完成」という言葉が二つに裂けていることを知る。**「あなたは、良い司書でした」**——その一言が労いにも断罪にも聞こえる場所で、プレイヤーは自分が何を降ろしてきたのかを、初めて当事者として引き受ける。
