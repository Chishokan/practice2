# 公開前チェックリスト（『貸出は三日まで』）

公開は fallback 設計のため画像未配置でも可能。以下を上から確認する。★＝ユーザー作業。

## 1. 画像アセット（D2）

- [ ] `public/assets/` に画像を配置（`docs/VISUAL_SPEC.md`／`public/assets/README.md` 参照）。
- [ ] 未配置でも公開可（fallback＝テキスト表示）。**推奨最低ライン＝妖精2形（guide/base・redeemed）＋タイトル（cg/title.webp）以上**。
- [ ] ★**AI生成画像の利用規約確認**：使用した生成ツールの**商用利用・Web公開の可否**、クレジット要否、学習除外要否を確認（ツールごとに規約が異なる）。問題があれば該当画像を差し替え／未配置（fallback）に。

## 2. 動作確認

- [ ] `npm run build` 成功（strict 型チェック込み）。
- [ ] `npm run preview` でタイトル → **E1 通し**／**TRUE 通し**がスモーク OK。
- [ ] ★**スマホ実機**確認（縦画面・タップ操作・立ち絵/背景のレイアウト崩れなし）。
- [ ] ★**主要ブラウザ**確認（Chrome / Safari / Firefox、iOS Safari 含む）。
- [ ] **セーブ（localStorage）**：中断→リロード→タイトル「つづきから」で復元。周回跨ぎの保持。
- [ ] 三態（画像なし／一部／全配置）いずれでも進行・表示が破綻しない。

## 3. メタ・OGP

- [ ] `og:title` / `og:description`（紹介文一字一句）/ `twitter:card` / favicon を確認。
- [ ] OGP プレビュー確認（例：各SNSのカードバリデータ）。SVG が出ない場合は PNG(1200×630) を用意し差し替え（`docs/DEPLOY.md` §4）。
- [ ] **ネタバレ点検**：メタ・README・公開文面に「消える」「妖精の名」「エンド構成」「隠し機構」への言及が無いこと。ジャンル表記は「図書館運営アドベンチャー」程度に留める。

## 4. 配布（Cloudflare Pages）

- [ ] ★`docs/DEPLOY.md` の手順で Pages プロジェクト作成・ビルド設定入力・デプロイ。
- [ ] ★`pages.dev`（または独自ドメイン）で公開URLを確認。
- [ ] 公開URLで再度スモーク（タイトル→通し・OGP）。

## 5. クレジット・締め

- [ ] クレジット表記（制作・使用ツール名）。**個人情報（本名・連絡先等）は載せない**。
- [ ] 公開文面（配布ページ・SNS 告知）にネタバレを含めない（§3 と同基準）。
