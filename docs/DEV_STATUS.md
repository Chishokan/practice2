## 6. 意図的な簡略化・技術的負債（レビュー観点）

1. **セーブは周回境界チェックポイント方式。** 周回途中の保存はしない。Phase 3 の目的（引き継ぎ・痩せの確認）には十分だが、途中復帰は将来対応。

4. **erasure.ts（消去の波及）未実装。** 現状は降ろした本を erasedBooks へ追加するのみ。visitorAmnesia 等の連鎖は Phase 6。
5. **来訪者の登場条件（conditions）未使用。** 3人が固定順で出るのみ。周回条件・フラグ条件は Phase 6。
6. **conscienceDelta は仮の重み。** バランス調整は Phase 6。
7. **UI 未装飾。** カラートークン・書体・台帳UIの作り込みは Phase 5。

### 10.1 3本の糸の裁定（確定）

第3章クライマックスに向けて独立/結合を判断すべきだった3つの糸を、次のとおり確定する。**3本は「三者ばらばら」ではなく、下記の対応で結ぶ／切る**を明示する（旧記述の「予約枠の正体＝金色の絵本」かつ「三者は別物」という自己矛盾を解消）。

| 糸 | 裁定 | 結合/独立 |
|---|---|---|
| **searchBlock 標的 `b09-kingdoms`** | **単独**。第3章で「検索から静かに消えるが整理には残る」機構の受け皿。child が第2章で残した「**見たのに無い**」体験を、第3章でプレイヤー自身が機構により追体験する**韻**。目録の創立コレクションからは除外（`content/catalog.ts` に b09 を入れない）。 | どの糸とも**結合しない** |
| **目録の予約枠 `cat-final`（`requiredBookId=null`）** | **「子の見た金色の絵本」と統合**。予約枠＝現存蔵書のどれとも一致せず永遠に埋まらない器で、その正体が金色の絵本。正体開示は第3章で行い、**TRUE ルートの鍵**（先代の手記＝妖精の名／childへの読み聞かせ）を担う。本セッションでは器のみ先置き。 | 金色の絵本と**結合** |
| **アンカー `b07-library-plan`** | 「最初の一冊」。TRUE の2段ゲートA（アンカー保全）の対象。上記2本と**無関係の独立の糸**。毎周復活の例外（§12.4）。 | 上記両者と**無関係** |
