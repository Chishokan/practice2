## 本の割り当て（既存優先・新規追加なし）

新規本の追加は不要。11冊が来訪者の正解に紐付き、`b07`（アンカー）だけは**意図的にどの正解にも割り当てない**：

- 既存で未使用だった `b01/b02/b10/b11/b12` を新3人へ割り当て（teacher=`b01`＋`b04`、tinker=`b12`＋`b02`、oldwoman=`b10`＋`b11`）。
- **`b07-library-plan`（アンカー）はどの来訪者の正解にもしない。** 第1章では目立たせない（「後から気づく」美学）。ただし常に書架に在り、teacher の場面でもプレイヤーは選んで渡せる（求められていない＝`genericAcceptScene` にフォールバック）。手渡しは貸出であり消去ではないので、書架に残る。
- `b09-kingdoms`（searchBlock 標的）は #2 船乗りの正解のまま。第3章での"検索から消える"演出と両立（H の申し送り参照）。

## メモ（申し送り）：teacher × アンカー の分岐余地（実装は Phase 6）

- teacher は **アンカー b07 を名指しで求めない**。だがプレイヤーは書架にある b07 を「選んで渡す／選ばない」を任意にできる（渡せば `genericAcceptScene`）。
- 狙い：**「1章で無自覚に手に取っていたかもしれない本を、3章で守ることになる」**という前半→後半の収束を仕込む。第1章ではアンカーを伏せたまま、触れうる位置にだけ置く。
- teacher が受け取った本（b07 か、別の本か）で後の周回・真相に差を出す**余地を残す**（分岐フラグの設計は Phase 6。今は申し送りのみ）。
- **前提の確認：手渡し（`handOver`）とアンカーの消失は別操作。** 消失は「整理で地下書庫へ降ろす（`removeFromShelf` → `erasedBooks`）」でのみ起きる。**アンカーを teacher に手渡してもアンカーは消えず、書架に残る**（コードで確認済み。次項）。

## 第1章のプレイ体験（3〜4文）

プレイヤーは、訪れる人々の小さな願いに本を選んで応え、感謝され、評判が上がっていく——温かく、少しユーモラスな図書館運営として第1章を過ごす。棚が手狭になれば古い本を地下書庫へ「整理」するが、それは事務作業にしか見えず、意味を疑う理由がない。台帳の一行がいつの間にか違う本になっていても、常連の老女が去年の貸出をうまく思い出せなくても、たいていは「自分の記憶違いだろう」と流して終わる。**プレイヤーは"良い司書"であろうと努めるほど本を降ろし、世界を痩せさせていることに——第1章では気づかない。**
